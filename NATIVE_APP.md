# Turning Mia's Games into a native phone app (Capacitor)

Written for: Salomé, to run herself. Claude has no terminal access in this project and cannot execute
any of this — it wrote every command and file it's allowed to touch, and marked the rest for you.

This wraps the existing build (`vite build` → `dist/`) in a native Android/iOS shell with
[Capacitor](https://capacitorjs.com/). It does not rewrite any game code — Candy Land, Popcorn
Land and Pet Me 3D run exactly as they do in the browser, just inside a native app window with
an icon on the home screen.

`capacitor.config.ts` is already in the repo root (Claude created it — it's a new file, not one
of the ones reserved for you). Everything below is what's left: installing packages and the two
small edits to files Claude doesn't touch (`package.json`, and optionally `index.html`).

## 1. Install Capacitor

```bash
npm install @capacitor/core
npm install -D @capacitor/cli
```

Android only needs its platform package; iOS only builds on a Mac with Xcode installed, so skip
that line if you're not on one:

```bash
npm install @capacitor/android
npm install @capacitor/ios   # Mac + Xcode only
```

## 2. Add these to `package.json`

Two small changes — a script, and the new dependencies (npm will have already added these when
you ran the installs above, just check they're there):

```jsonc
// in "scripts"
"build:app": "vite build && npx cap sync",

// in "dependencies"
"@capacitor/core": "^<version npm installed>",
"@capacitor/android": "^<version npm installed>",  // if you added Android

// in "devDependencies"
"@capacitor/cli": "^<version npm installed>",
```

## 3. Add the native platform project(s)

This creates an `android/` folder (and/or `ios/`) with the actual native project — these folders
are generated by the tool, not written by hand:

```bash
npx cap add android
npx cap add ios      # Mac + Xcode only
```

## 4. Build the web app and sync it into the native shell

Run this every time the game code changes and you want to see it in the app:

```bash
npm run build:app
```

## 5. Open and run it

```bash
npx cap open android   # opens Android Studio
npx cap open ios       # opens Xcode (Mac only)
```

From there, press the Run button in Android Studio / Xcode to install it on a connected phone
or an emulator/simulator — that's the "app on my phone" step. Publishing it to the Play Store or
App Store is a separate, later step (a developer account, store listing, review process) — ask
if you want that written up too once you've got it running on a device.

## 6. Optional: a nicer status bar on the phone

Native phones have notches and home-indicator bars. One line in `index.html`'s `<meta name="viewport">`
tag makes the game draw edge-to-edge instead of leaving a plain bar:

```html
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
```

(Just the `viewport-fit=cover` added to the end of what's already there.)

## Optional: a real icon

Right now the app will use Capacitor's placeholder icon. To use your own:

```bash
npm install -D @capacitor/assets
```

Then put one square image (1024×1024px, no transparency) at `assets/icon.png`, and one at
`assets/splash.png` (2732×2732px) for the loading screen, and run:

```bash
npx capacitor-assets generate
```

It generates every size Android/iOS need automatically.
